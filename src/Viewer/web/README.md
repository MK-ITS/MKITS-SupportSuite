# Browser viewer (planned – Phase 9)

TypeScript viewer served by the MKITS server. Renders the remote screen on an HTML5 canvas
(WebCodecs H.264), forwards mouse/keyboard input, and provides chat, file transfer, clipboard and
terminal (xterm.js). Session payloads are end-to-end encrypted with WebCrypto.

See [WORKPLAN.md – Phase 9](../../../WORKPLAN.md) and [ADR-0003](../../../docs/adr/0003-viewer.md).
