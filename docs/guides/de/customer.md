# Fernwartung – so funktioniert es für Sie

Ihr Supporter möchte sich Ihren Computer ansehen, um Ihnen zu helfen. Hier steht, was dabei passiert und was Sie
jederzeit selbst in der Hand haben.

## Start

1. Ihr Supporter nennt Ihnen einen **8-stelligen Code**, meist am Telefon.
2. Öffnen Sie die Adresse, die Ihr Supporter nennt (z. B. `https://support.example.com`), und geben Sie den Code ein.
3. Laden Sie das Support-Programm herunter und starten Sie es:
   - **Windows:** `MKITS-Support-….exe`. Windows warnt eventuell vor einem unbekannten Programm (*Weitere Informationen →
     Trotzdem ausführen*). Keine Installation, keine Administratorrechte nötig.
   - **Linux:** die `.AppImage`-Datei. Machen Sie sie ausführbar (Rechtsklick → *Eigenschaften → Ausführen erlauben* oder
     `chmod +x MKITS-Support-*.AppImage`) und starten Sie sie.
4. Das Programm zeigt den **Namen Ihres Supporters** und die **Adresse des Servers**. Prüfen Sie beides. Nur wenn es
   stimmt, klicken Sie auf **Erlauben**. Wenn Ihnen etwas merkwürdig vorkommt, klicken Sie auf **Ablehnen** – dann
   passiert nichts.
5. Unter Linux mit einem modernen Desktop (Wayland) fragt Ihr System zusätzlich, welchen Bildschirm Sie freigeben.

## Während der Sitzung

- Das Fenster des Support-Programms bleibt offen und zeigt, wer verbunden ist. Solange es offen ist, sieht Ihr
  Supporter Ihren Bildschirm und bedient – wenn Sie es erlaubt haben – Maus und Tastatur.
- **Sicherheitscode:** Das Fenster zeigt einen kurzen Code. Wenn Ihr Supporter danach fragt, lesen Sie ihn vor; stimmt
  er mit seinem überein, ist die Verbindung zwischen Ihnen beiden Ende-zu-Ende verschlüsselt und niemand sonst kann
  zusehen.
- **Chat:** Im Fenster können Sie Ihrem Supporter Nachrichten schreiben.
- **Dateien:** Will Ihr Supporter Ihnen eine Datei schicken, werden Sie vorher gefragt; angenommene Dateien landen in
  Ihrem Ordner *Downloads*. Mit *Datei senden …* schicken Sie Ihrem Supporter eine Datei.
- **Administratorrechte (Windows):** Für manche Aufgaben bittet Ihr Supporter Sie eventuell, auf **Mit
  Administratorrechten neu starten** zu klicken und die Windows-Abfrage zu bestätigen. Dann kann er auch
  Windows-Sicherheitsabfragen bedienen. Dieser Modus endet mit der Sitzung.

## Beenden

Klicken Sie auf **Sitzung beenden** oder schließen Sie einfach das Fenster – die Verbindung endet sofort. Das Programm
installiert nichts und bleibt nicht auf Ihrem Computer; die heruntergeladene Datei können Sie danach löschen. Für eine
neue Hilfe brauchen Sie einen neuen Code.

## Dauerhaft installiert

Firmen installieren den Support-Agent manchmal dauerhaft auf ihren Computern. Dann braucht niemand einen Code; je nach
Einstellung Ihrer Firma werden Sie gefragt, bevor sich ein Supporter verbindet, oder Sie sehen einen Hinweis, solange
jemand verbunden ist. Fragen dazu beantwortet Ihre IT-Abteilung.
